About RelayDrop

A straightforward way to hand off files for a limited time.

A temporary handoff, with clear limits

RelayDrop helps you send a small collection of files without creating a permanent shared folder. Upload your files, choose when the transfer expires, and give your recipient a link or an eight-digit code.

It is useful for everyday handoffs such as design proofs, class notes, event photographs and documents you have permission to share. Keep your own originals: RelayDrop is a transfer service, not a backup archive.

What you can send

Up to 20 files in a transfer.

Up to 50 MiB for an individual file and 100 MiB for all files combined.

Expiry choices of one hour, 24 hours, three days or seven days.

An optional transfer password, plus a shareable link, QR code and barcode.

Sender controls that let you revoke a transfer before its expiry.

How sharing works

A sharing link and an eight-digit code are two routes to the same transfer. A QR code is a convenient way to open the link on another device; it does not add an extra security layer. Anyone who obtains the link or code may access an active unprotected transfer, so share them only with the people you intend to receive the files.

A password restricts downloads, but files are not end-to-end encrypted. RelayDrop does not automatically scan uploads for malware. For confidential material, encrypt the files yourself before uploading, and send the password through a separate channel.

Responsible sharing

Send only files you are allowed to distribute. If a transfer looks harmful, unlawful or unauthorized, use Report abuse. For a service question, use Contact. These forms create a ticket for operator review.
