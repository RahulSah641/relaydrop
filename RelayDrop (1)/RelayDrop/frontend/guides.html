A practical checklist before you send files

Check the contents, choose the access rules, and make the handoff easy for your recipient.

1. Make a clean handoff folder

Collect only the files your recipient needs. Open each one once to check that it is the intended version. Remove unused drafts, hidden worksheets, document comments or other material you did not mean to share. Give the files useful names, such as Event-Poster-Proof-03.pdf, rather than a chain of names ending in final-final.

Review filenames as well as contents. A filename can reveal a customer's name or project detail before someone opens the file.

2. Check size and permission

A RelayDrop transfer accepts up to 20 files, each at most 50 MiB, with no more than 100 MiB in total. A group can exceed the total limit even when every individual file fits. Reduce image dimensions only if the recipient does not need the originals; for print production, confirm the required resolution before shrinking a file.

Send only content you own or have permission to distribute. For a document containing someone else's personal information, check that sharing it is appropriate and authorized.

3. Decide how much protection you need

Choose a password for material you do not want accessible through the link alone. Send that password by a different route from the transfer link when practical. The password is an access check, not end-to-end encryption. For sensitive material, use a suitable encrypted file or archive before uploading and keep its encryption password separate.

A recipient needs the link or sharing code, and the transfer password if enabled. Keep access to the browser that created your transfer if you may need to revoke it later. If you upload while signed in, you can also manage that transfer from your account on another device.

4. Finish the handoff

Wait for the transfer confirmation before sharing anything. Tell the recipient what the files are, how many to expect and when the transfer expires. Ask them to save their own copy before the deadline. Keep your originals until you know the handoff is complete.

If you shared the wrong transfer, revoke it and create a corrected one. Revocation prevents future normal downloads; it cannot erase a copy someone has already saved.

Choose an expiry that fits the handoff

Balance the recipient's schedule with how long the link needs to remain usable.

Start with the recipient's next opportunity

Choose the shortest expiry that gives the recipient a realistic opportunity to download. A colleague waiting in the same meeting needs a different window from a collaborator who will return after the weekend. Tell the recipient the deadline explicitly instead of assuming they will open the link immediately.

Four useful windows

One hour: a live handoff when the recipient is already available.

24 hours: an everyday handoff expected to be collected within a day.

Three days: a recipient working a different schedule or needing a little more time.

Seven days: a planned handoff with a longer collection window; remind the recipient to keep a local copy.

Expiry and revocation do different jobs

Expiry closes the transfer automatically after the selected window. Revocation lets the sender close it earlier through the original browser or, for a transfer uploaded while signed in, the associated account. Use revocation if the recipient confirms receipt and no further downloads are needed, or if the link was sent to the wrong person.

Both affect future access through the service. Neither can recall a downloaded file or prevent someone from forwarding a copy they already saved. Time limits help reduce how long a link remains useful; they are not a substitute for choosing the right recipients.

Plan for missed deadlines

Keep the source files outside RelayDrop. If the recipient misses the deadline, create a new transfer and send the new details. If a deadline is important, verify receipt before it passes instead of relying on the sharing link as your only record.

Receive files safely and solve common download problems

Know which details you need, what to check, and when to ask for a new transfer.

Confirm the handoff first

If a transfer is unexpected, confirm it with the sender through a channel you already trust. A familiar-looking filename is not proof that a file is safe. Ask what the transfer contains and whether it requires a password.

Open the link or enter the full eight-digit code, including any leading zero. A QR code opens the sharing destination and the barcode represents the code; neither verifies the sender or adds encryption. If a password was set, ask the sender for it through a trusted channel.

If the code or password is rejected

Copy the code again and check that it has eight digits. For a protected transfer, enter the password exactly as supplied. Do not keep guessing passwords or codes. Ask the sender to confirm the details through a trusted channel.

An unavailable transfer may have expired, been revoked or been removed. The sender may need to create a new transfer. Repeatedly refreshing the same expired link will not restore it.

If a download does not finish

Check your internet connection, available device storage and the browser's downloads list. Keep the browser open until the download completes. If your browser or security software blocks the file, investigate the warning rather than disabling protection simply to get the file.

Try downloading again while the transfer is still active. If the problem continues, contact the sender or create a support ticket with the transfer code, browser, approximate time and exact error. Do not include the transfer password.

Before opening the files

RelayDrop does not automatically scan uploads for malware. Scan downloaded files with your own security software, pay attention to unexpected file extensions, and be cautious if a document asks you to enable macros or install additional software.

Save files you need before the deadline and confirm receipt with the sender. If you notice suspected malware, unauthorized material or another harmful transfer, use Report abuse instead of forwarding it to more people.
